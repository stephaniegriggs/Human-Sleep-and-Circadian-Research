# Images Directory

This directory contains images and visual assets for the Human Sleep and Circadian Research repository.

## Directory Structure

- `profiles/` - User profile images and team photos
- Additional subdirectories can be added as needed for documentation, figures, and diagrams

## Adding Images

To add an image to the repository:

1. Place your image file in the appropriate subdirectory
2. Reference it using relative paths, for example:
   - In README: `![Profile](images/profiles/Picture1.png)`
   - In markdown files: `![Description](../images/profiles/Picture1.png)`

## User Profile Image

To add a user profile image:

1. Save your image as `images/profiles/Picture1.png` (or your preferred filename)
2. Reference it in the main README.md or documentation as needed

**Note**: Previously, images may have been referenced using absolute local paths like `/Users/stephaniegriggs/Desktop/Picture1.png`. These should be updated to use relative repository paths for portability.
